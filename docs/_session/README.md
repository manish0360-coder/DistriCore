# Session scratchpad — NOT part of the documentation corpus

Everything here is **untracked, disposable and non-authoritative**. Never cite it as a
source. Delete at milestone close.

Its only legitimate content is **negative results** — approaches tried and rejected, and
why. That is the one thing genuinely lost when a session ends and the one thing git does
not record (ADR-0005 §5.4).

`NOTES.md` in this directory is git-ignored.
